# `assets/models` — optional glTF aliases

Logical names (`bat`, `ball`, `diamond`, `plaza`, `tree`, `block`, `coin`, …)
resolve here. See [`docs/ASSET_CLIPS.md`](../../docs/ASSET_CLIPS.md).

Refresh from Kenney CC0 packs:

```bash
python tools/install_kenney_assets.py
```
