# Prompt — 共通コア移植スライス①: 文字描画

> 3ジャンル計画（トルネコ / SLG / バニーガーデン）の検討で、0.19 由来の
> 「音・文字・2D・モーション・入力の拡張」が shared wgpu 30 に無いことが
> 監査で判明。方針として「まずはどんなゲームにも必要なこれから」（共通コア
> の移植）が選ばれた。ECS は入れない（確定）。

このスライスの指示（実質）:

- shared wgpu 30 に**文字描画**を入れる。Python ゲームマスター
  （`kagra.gameloop.Scene/run`）から「テキスト + 四角」の HUD を世界の上に
  重ねて描けるようにする。
- ゲームロジックは Python のみの原則を守る: Rust は受け取った HUD データを
  描くだけ。Python は dump と hud dict を渡す。
- 3ジャンル（トルネコ/SLG/バニーガーデン）は全部「メッセージ・メニュー・
  数値」を必要とするので、日本語テキストが描けること。
- 新パイプライン / テクスチャ追加はしない方針（既存の 2D HUD パス = フラット
  カラーの Quad 列をそのまま使う）。グリフの点灯画素を 1px Quad に展開する。
- 各スライスはコミット + テスト + ログ（docs/agent-runs/）を閉じる。
