# Session

1. 素材の棚卸し: 同梱済みの Kenney（graveyard-kit の亡者 5 体・墓石・十字架・かぼちゃ・ランタン）と効果音・BGM。新しい素材は足さない。
2. 遊びを決める: Moonlit Swarm（スティックで動く）と違う操作にする。**タップだけ**の防衛。真ん中のランタンへ歩いてくる亡者をタップで倒し、90 秒（夜明け）まで守る。ゾンビは 3 回、当てたら押し戻す、空振りでコンボが切れる。
3. 雛形: `python scripts/new_kit.py lantern_watch "Lantern Watch"`（登録・ワールド・マニフェスト・example が 1 コマンド）。
4. エンジンに戻したもの:
   - `game_core::view`（Moonlit Swarm の project / ground_at を共有に。`View::fit` と `View::frame` で縦持ちでも横持ちでも決めた範囲が画面に入る）。
   - 躓き: Starter のカメラは縦持ちで盤面の左右が切れていた（fov 50 固定）。`View::frame` に替え、テストで四隅が画面内にあることを確かめる。最初の `fit`（中心の距離で幅を合わせる）は手前の角が広がるので外れた → 点の集合で必要角を出す形に直した。
   - Starter に音（BGM と効果音）。新しいゲームは最初から鳴る。
   - `Motion::parse`（JSON で体の動きを選べる）。
5. 絵の調整（ヘッドレス Chromium のスクショ 3 往復）: 1 回目は真っ黒（霧が近すぎて全部霧の色）、2 回目は白飛び（墓石が白、空が紫に見える）、3 回目で床を広げ・墓石を暗く・ランタンの光を床に落として、暗い夜に灯りの輪。
