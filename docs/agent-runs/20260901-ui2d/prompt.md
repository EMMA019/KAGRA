# Prompt — 共通コア移植スライス②: 2D UI パネル

> 前スライス（① 文字描画、`9f68160`）で shared にテキストが入った。
> 次は「どんなゲームにも必要な」UI パネル。3ジャンル（トルネコ / SLG /
> バニーガーデン）は全部メッセージウィンドウ・選択肢・リスト・バーを
> 必要とする。

指示（実質）:

- Python 側（`kagra/ui2d.py`）に 2D UI 部品を組み、`draw_world` の hud dict
  （quads + texts）に変換する。ゲームロジックと同じく全部 Python。
- 部品: メッセージウィンドウ（折り返し対応）/ 選択肢メニュー（カーソル）/
  プログレスバー / リスト。パネル（枠 + 中身）。
- 折り返しは shared の実測幅を使う（`kagra_shared.measure_text` を公開）。
  kagra_shared が無い環境は近似幅（CJK 1em / ASCII 0.5em）で動く。
- デモ: トルネコ風の 1 枚（メッセージ + 選択肢 + HP/EXP バー + 在庫リスト）
  をヘッドレス PNG で出す。
- 各スライスはコミット + テスト + ログ（docs/agent-runs/）を閉じる。
