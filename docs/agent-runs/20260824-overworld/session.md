# Session — 2026-08-24 Overworld island

ユーザーは 3D オープンワールドのスーパーマリオ風（海・山・草原）を行けるようにしたい、と書いた。

Rapier / ボクセル / チャンクストリーミングは入れない（ロードマップの釘）。
`Physics3D.set_height_fn` はすでにあったので、公開面に繋いだ。

## 決めたこと

- 1 枚の高さ関数で島にする。西が海、中央が草原、北東が山。
- 崖は勾配で止める。水は浮力。`Walk(..., jump=)` で SPACE / A。
- これはハブの島であって、オデッセイのキングダムではない。正直にドキュメントへ書いた。
