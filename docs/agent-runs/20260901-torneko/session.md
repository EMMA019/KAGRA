  - ダンジョン: `MapGen.dungeon(17, 17, seed=floor_seed)`（floor_seed =

## 躓き

1. **MapGen.dungeon は 16x16 未満で落ちる**: 部屋サイズが
   `randint(4, cols//4)` で、cols=15 だと `randint(4, 3)` → ValueError。
   ダンジョンを 17x17、窓を 480x300 に拡大。
2. **貪欲方針が壁で詰まる**: まっすぐ階段へ進むだけだと壁に当たって
   停滞（ブロックされた移動はターン消費しないので 800 ターン無駄）。
   BFS 経路探索に置換。
3. **テストの壁隣接前提ミス**: プレイヤー開始点（部屋中央）は壁に隣接
   しない。テストは「床に隣接する壁」を探索してから検証するよう修正。
4. **決定論の検証で PNG 不一致を 1 回観測**（旧貪欲方針時代）: セーブ状態
   は完全一致していたが PNG のハッシュが違った。現行 BFS コードでは
   プロセスを跨いだ 2 実行がバイト一致（MD5 一致 ×2 回確認）。同じ dump の
   クロスプロセス描画もバイト一致、prop id の違いも描画に影響しないこと
   を別途確認。ロジック・描画とも決定論と判定。
