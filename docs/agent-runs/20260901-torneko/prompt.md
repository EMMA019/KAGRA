# Prompt — 2 本目ジャンル: トルネコライク

> 3 ジャンル計画の 2 本目（バニーガーデンに続く）。共通コア（文字 / UI /
> 音 / マウス）は済み。1 本目は世界が静止するゲームだったので、今度は
> 「seed 決定論 + グリッド + ターン + 在庫」という別系統を検証する。

指示（実質）:

- **ゲームロジックは全部 Python**（`Scene.update`）。ダンジョン生成は既存の
  `kagra.mapgen.MapGen.dungeon(cols, rows, seed=...)` を使う（同じ seed →
  同じ部屋・通路・階段）。
- **決定論**: 敵配置・アイテム配置・戦闘ロールも seed + 階数から決まる
  （`random.Random(floor_seed)`）。`--seed 12345` を 2 回回すと状態も描画も
  完全一致すること。
- ターン制: プレイヤーが動く/攻撃 → 敵が動く。敵 AI は近接攻撃 / 6 マス
  以内を追跡 / 低速徘徊。
- 在庫: 薬草（回復 15）/ ちからの種（攻撃 +2）。X でメニュー。
- セーブ: JSON スナップショット（seed / 階 / 位置 / HP / 在庫 / 敵 /
  RNG 状態）。ロードで完全再現（未来のロールまで一致）。
- ゴール: 各階の下り階段 → 3 階で脱出（win）。死んだら Z でやり直し。
- 描画は「世界はデータ」: ターン制なので状態変化時（dirty）だけ dump dict
  を作り直して `draw_world` で描く（毎フレーム描画しない）。
- ヘッドレス verify: `--headless out.png --seed N --turns M` — BFS で階段を
  目指すスクリプト方針で M ターン遊んで PNG + 状態 JSON。
- テストは純ロジック（kagra_core / kagra_shared 非依存）。コミット + ログ。
