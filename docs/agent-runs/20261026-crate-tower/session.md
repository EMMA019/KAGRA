# Session

1. 遊びを決める: Lantern Watch（タップ防衛）とも Moonlit Swarm（スティック）とも違う操作にする。**ワンボタンのタイミング**。ゆれる木箱をタップで落として塔を積む。ど真ん中はぴったり（四角に揃い、連続でボーナス）、端すぎると落ちてライフを失う、ずれて積むと塔のバランスがかたむき、限界をこえると倒れる。10 個目ごとに宝箱。
2. 素材: platformer-kit の木箱と樽、mini-dungeon の宝箱、space-kit の建物を遠景に。新しい素材なし。
3. 雛形: `python scripts/new_kit.py crate_tower "Crate Tower"`。共有の `View::frame` でゆれ幅と塔の上が縦でも横でも画面に入る（テスト）。
4. テスト 8 件が一回で通った（ぴったりとコンボ、ミスでライフ、かたむいて倒れる、宝箱と加速、一度に一つ・Space・一時停止、縦横で画面内、焼いたワールド）。
5. 絵（スクショ 3 往復）: 1 回目は格納庫が近すぎて画面の半分、空がページの紫に見えた → 遠くに暗い壁と遠景を小さく。結果画面の列名が英語のままだった → `col.height` などを i18n に足し、`perfects` を既存の `perfect` 列に合わせた。
