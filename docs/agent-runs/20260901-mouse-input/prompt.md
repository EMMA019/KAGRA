# Prompt — 共通コア移植スライス④: 入力拡張（マウス）

> 監査で「ゲームパッド / IME / マウスホイール・ロック」は 0.19 のみと
> 判明。バニーガーデン系は会話ウィンドウをマウスで選ぶので、まず
> マウスの位置・ボタン・クリックが必要。

指示（実質）:

- `kagra.gameloop` の tkinter 窓にマウス入力を足す: `mouse_pos()` /
  `mouse_down(button)` / `mouse_clicked(button)`。1=左 / 2=中 / 3=右。
- キーと同じく「このフレーム押された瞬間」をフレーム開始時にクリア。
- テストはハンドラを直接叩く（tkinter 不要の純ロジック）。
- ゲームパッド / IME はこのスライスでは対象外（依存の追加が必要になるため
  後回し。バニーガーデンはキー + マウスで足りる）。
- 各スライスはコミット + テスト + ログを閉じる。
