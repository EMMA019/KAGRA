# Session (round 1)

1. 計画: 3 回に分けてプレビューを出す（体と 2 面 → 敵と面 → ボスと仕上げ）。素材は同梱のみ（Kenney Space Kit、Mini Characters、Platformer Kit のジュエル）。
2. エンジン: `game_core::platform` を新規（テスト 6 件。ダッシュの穴越えテストは最初 7.5 m で失敗、ジャンプ 4.6 m + ダッシュ 2.4 m の計算から 5.8 m に）。`KitHost::buttons` でダッシュのボタンをキットへ（ページは Shift とパッド B/X も送る）。
3. 雛形: `python scripts/new_kit.py station_escape "Station Escape"`。ステージは `station_escape/stages.rs`、テストは `station_escape/tests.rs` に分けた（巨大ファイルを作らない）。
4. ボット: 経路の x を順に目指し、端・壁・トゲで跳び、着地点が無ければ頂点でダッシュ、レーザーと離れたリフトは待つ。
   - 1 面: 最初はダッシュの穴（6 m）で落ちた → ボットが「前に床が見える」とダッシュしない作りだった。頂点で着地点を予測する形に直し、穴も 5.7 m に。
   - 2 面: 最後のレーザーの直後のトゲ → リフトが上にいる時に落ちる。トゲを 2 m に縮め、ボットにリフト待ちを入れた。
5. 絵: 縦持ちで床の下が真っ黒 → 床のスラブを下まで伸ばして見せる。背景の建物が近すぎ → 奥へ 1.6 倍。
