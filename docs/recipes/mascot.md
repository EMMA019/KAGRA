# Desktop mascot

English below. 日本語は後半。

```bash
python -m kagra --mascot --vrm me.vrm
```

Always-on-top, no window chrome, looks at the mouse. Song and dance loop. ESC quits.

`--mascot` implies `--loop`. Combine with your own clip:

```bash
python -m kagra --mascot --vrm me.vrm --song my.wav --dance wave.vrma
```
