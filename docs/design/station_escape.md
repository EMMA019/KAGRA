# Station Escape — design

最終更新: 2026-10-27。Emma の注文:「次はもう少し大作寄り」→ 3 案から「宇宙基地の脱出アクション」。

## 何のゲームか

崩れていく宇宙ステーションを、走って・跳んで・ダッシュして脱出する横向き 3D アクション。
ステージクリア型、短い物語つき。スマホ縦でも横でも遊べる。ゲームオーバーなし（落ちたらチェックポイントから）。
スコアは「クリア + セル + パー以下の秒数 − ミス」。

## 操作

| 入力 | 動き |
|---|---|
| 左半分の親指（浮くスティック、横だけ使う） / A D / ← → / ゲームパッド左 | 走る |
| 右下 JUMP（右半分のどこでも可） / Space / ゲームパッド A | ジャンプ（長押しで高く） |
| DASH ボタン / J K Shift / ゲームパッド B X | ダッシュ（空中で 1 回） |

## 部品（エンジンに戻したもの）

- `game_core::platform` — 体。コヨーテタイム、先行入力、短押しで小ジャンプ、空中ダッシュ 1 回、すり抜け足場、動く足場に乗る。
- `KitHost::buttons` — ジャンプ以外のボタン（J/K/Shift、パッド B/X）をキットに渡す。
- 永続プロップ（ステージごとに 1 回組み、毎フレームは位置と表示だけ変える）+ `declare_models`。

## ステージ（JSON、`game.stages`）

ブロック（solid / oneway / crumble / move）、レーザー（on/off 周期）、トゲ、セル、チェックポイント、ヒント、背景の飾り、出口。
既定は 2 面:

1. ドッキングベイ — 走る、跳ぶ、点滅レーザー、足場渡り、トゲ、ジャンプ + 空中ダッシュ。
2. リアクターリング — 動くリフト、崩れる足場、レーザー、縦に登る、上下に動くリフト。

自動テストのボットが 2 面とも最後まで通す（ステージが遊べることの確認）。

## 予定

| 回 | 中身 |
|---|---|
| 1（この PR） | 体と操作、2 面、物語カード、クリアカード、音 |
| 2 | 敵（巡回ドローン、砲台の弾）、3〜4 面 |
| 3 | ボス、ステージ選択と記録、演出の仕上げ |
