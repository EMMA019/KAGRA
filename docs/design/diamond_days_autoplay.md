# 白球デイズ 自動プレイ統計

バランスを「感触」ではなく数字で追うための仕組み。コーチ役のボットが、プレイヤーと同じ画面・同じボタンで何年も遊び、試合数・勝率・成長・名声などを表にする。ゲーム本体は一切変えない（画面と、ゲームが元から持っている記録を読むだけ）。

## 使い方

```bash
# CI でも走る短縮版（1 シード × 2 年、2 回走らせて結果が同じことを確かめる。約 2 秒）
cargo test -p kagra-shared --lib autoplay_smoke

# フル実行（5 シード × 10 年、デバッグビルドで約 7 秒）
cargo test -p kagra-shared --lib autoplay_baseline -- --ignored --nocapture
#   → target/autoplay/autoplay.md と autoplay.json
```

環境変数: `KAGRA_AUTOPLAY_SEEDS`（シード数。既定 5）、`KAGRA_AUTOPLAY_YEARS`（既定 10）、`KAGRA_AUTOPLAY_OUT`（出力先）、`KAGRA_AUTOPLAY_SPEND=1`（練習ポイントを毎週手で使う）、`KAGRA_AUTOPLAY_GACHA=1`（無料スカウトを全部引く。下の「既知の問題」を参照）。

変更の前後を比べるときは、同じ設定で 2 回走らせて `autoplay.json` を差分で見る。`summary` に項目ごとの平均・標準偏差・最小・最大が入っていて、`per_seed` に各シードの年ごとの数字が入っている。同じシードは同じ結果になる（別プロセスで 2 回走らせて、md も json もバイト単位で一致）。

スモークテストは「動くこと」と「同じシードで同じ結果になること」しか見ない。バランスの数値でテストを落とすことはしない（異常値の基準は、結果を見てから人と決める）。

## 方法

- **コーチの動き（既定）**: 毎週 1 枚目のカードを出す。試合は結果までスキップ（作戦は選手任せ）。出来事・会話は 1 番目の答え。練習ポイントはゲーム自身の月次の自動成長に任せ、手では使わない。スカウト（ガチャ）は引かない。3 年ごとの区切りは「この学校で続ける」。
- **シード**: 1〜5（`DiamondDaysSpec.seed`）。サイコロはすべてこのシードから決まる。
- **年数**: 10 年（3 年の章を 3 つ半）。最後の年の卒業まで含める。
- **試合の記録**: 試合が終わった瞬間（結果画面の前）の試合ログから、種別・勝敗・得点・エラー（`PlayKind::Error`）・打席数を読む。種別はゲームが勝敗を記録するときと同じ判定（`game_this_week()`）。
- **着地**: カードの歩きが終わった時点の盤上のマス。冬の練習試合マスは試合がない（紅白戦）ので別に数える。
- **成長**: 毎週の初めに全選手（部員と引退した 3 年生）の能力を記録し、初めて見た週を「入部時」、最後に見た週を「卒業時」とする。最初からいた選手は入部時が分からないので除く。野手は ミート・パワー・走力・守備・捕球・肩 の平均、投手は 球速（0〜100 に直す）・制球・スタミナ・変化球 の平均。
- **名声・プロ入り**: 年の終わりの `reputation`、`pros`（年ごとの人数）。
- **自己チェック**: 数えた試合数が、ゲーム自身の年ごとの勝敗記録（`history`）と全シード・全年で一致することを毎回確かめる。

## 気になる点

異常と決めつけず、数字と場所だけ書く（基準は結果を見て人と決める）。20 シードで走らせ直しても同じ傾向（全体の勝率 84.8%、得点 8.6 対 失点 1.6、10 年目の卒業生 8.8 人のうちプロ入り 8.8 人）。

1. **強すぎる**: 全体の勝率 82.6%、1 試合の得点 8.2 に対して失点 1.7。1〜3 年目は 56〜64% だが、6 年目以降は 84〜95%。全国優勝は 50 年中 2 回（4%）。
2. **名声が 8 年目で頭打ち**: 開始 5 → 3 年目 27 → 6 年目 82 → 8 年目に全シードで上限 100。以後の 3 年は動かない。長く遊ぶ（10 年以上）ための伸びしろがここで尽きる。
3. **卒業生がほぼ全員プロ入り**: 8 年目 7.4 人中 7.4 人、9 年目 7.8 人中 7.6 人、10 年目 8.8 人中 8.8 人。1〜3 年目は 0〜0.8 人。名声が 100 に近づくと全員プロになっている。
4. **成長が項目で偏る**: 野手のミートは +21.9、守備・捕球・肩は +9〜10。投手の球速は +16.7 km/h。
5. **エラーが少ない**: 両校合わせて 1 試合 0.46 個（100 打席あたり 0.6）。自校 0.18、相手 0.28。
6. **練習試合は年 2 回ほど**: 年 2.0 回（20 シードでは 2.3 回）。着地「練習試合」は年 3.2 回で、そのうち 1.1 回は冬（紅白戦、試合なし）。マスの着地は盤面の構成どおりに散らばっている（実際/期待 0.87〜1.11）。
7. **年間試合数が増えていく**: 1〜3 年目は 6〜7 試合、10 年目は 16.4 試合（全国・春の招待に出る年が増えるため）。

## 既知の問題

- `KAGRA_AUTOPLAY_GACHA=1` でシード 4 を走らせると、章の 3 年目の夏の大会のあと（19 週目、続く練習試合）に `sim.rs` の `pitcher_now()` が範囲外アクセス（`arms` が空）で落ちる。そのとき名簿の投手は 4 人とも 3 年生で、夏の引退で全員が名簿から外れ、投手が 0 人のまま試合に入る。`Team::recruit` は「名簿の投手が 3 人未満なら投手を補う」と数えるが、その人数には引退する 3 年生も入っているので、ガチャで投手が増えると補われない。既定のコーチでは 20 シードでも起きなかったが、ガチャを引く普通のプレイで起こりうる。この PR は本体を変えないので、そのままにしてある（直すなら別 PR）。
