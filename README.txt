Lumen
Open play.html over http (a file:// page cannot load wasm).
python -m http.server -d <this folder> 8000
Keyboard: WASD or arrows, Shift or Space boosts, P pauses, Enter starts.
Touch: drag to steer, BOOST button, tap the title to start.
Sound clips are the CC0 tones in assets/audio/LICENSE.txt.
